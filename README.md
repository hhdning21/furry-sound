# Music → Animation MVP (Hackathon)

This project converts uploaded music into a real-time animation.

## What this MVP does

1. Open web page → see a large canvas + audio upload/preset area.
2. Upload MP3/WAV (or choose preset).
3. Click Analyze this song:
	- Frontend sends audio to backend.
	- Backend runs Python `librosa` analysis and returns JSON:
	  - `mood`
	  - `palette`
	  - `animationStyle`
	  - `motionSpeed`
	  - optional `sections`
4. Click Play:
	- Frontend uses Web Audio API for real-time frequency analysis.
	- Canvas animation is driven by:
	  - backend JSON config +
	  - real-time low/mid/high/volume features.

- Frontend: React + TypeScript + Vite
- Visuals: Canvas 2D

## 1) Backend setup (Node + Python librosa)

### Install Node dependencies

From [backend](backend):

`npm install`

### Create Python virtual environment

From [backend](backend):

`python3 -m venv .venv`

Activate it:

- macOS/Linux: `source .venv/bin/activate`

Install Python dependencies:

`pip install -r requirements.txt`

### Environment variables

Copy [backend/.env.example](backend/.env.example) to `.env`:

`cp .env.example .env`

Minimal useful values:

- `PORT=8787`
- `PYTHON_BIN=python3` (or full path like `.venv/bin/python`)

> `GEMINI_API_KEY` is optional now. Current analysis is done by Python librosa.

### Start backend

From [backend](backend):

`npm run dev`

Health check:

`GET http://localhost:8787/health`

## 2) Frontend setup

## 3) How to test quickly

### Browser test

1. Open app.
2. Upload MP3/WAV or pick a preset.
3. Click Analyze this song.
4. Confirm Gemini output card shows mood/style/speed (now generated by librosa mapping).
5. Click Play and confirm:
	- low frequency pulses center shape,
	- high frequency increases particles/sharpness,
	- volume affects overall brightness.

### API test with curl

`curl -X POST http://localhost:8787/analyze -F "audio=@/absolute/path/to/test.mp3"`

Expected response shape:

`{ "analysis": { ... }, "audioFeatures": { ... } }`

## Notes for demo

- Keep songs around 30–60 seconds for stable demo speed.
- If Python command is not found, set `PYTHON_BIN` in backend `.env` to the exact interpreter path.
- If analysis fails, check backend logs first.
